JSON
----

https://jsonic.io/guides/json-types

JSON has exactly 6 data types:
* string	- double-quoted UTF-8
* number	- IEEE 754 double-precision float
* boolean	- true/false, unquoted
* null		- unquoted
* array		- ordered list
* object	- unordered key-value pairs

No integers, dates, undefined, or functions.
